# Предметное уточнение

1. Прочитайте `CONTEXT.md`.
2. Сверьте термины запроса с доменным словарём.
3. Найдите отсутствующие границы, входные данные и условия готовности.
4. Задайте уточняющие вопросы вместо выдумывания фактов.
5. После ответа обновите спецификацию и проверьте её командой `make validate`.
