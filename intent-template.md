# Шаблон замысла изменения (intent)

Сначала уточните обращение. Записывайте потребность понятным языком; неизвестное оставляйте вопросом.
Инициатор подтверждает исходный смысл, владелец продукта — принятие. Аналитик помогает уточнять.
Файл для одного запроса имеет содержательное имя в `intents/`; его историю хранит Git.
