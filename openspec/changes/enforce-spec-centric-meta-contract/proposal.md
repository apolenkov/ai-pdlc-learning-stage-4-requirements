## Why

Метарепозиторий смешивает подготовку требований с установкой и запуском сервиса. Учебный маршрут должен показывать одного владельца требований на каждой ступени и не требовать синхронизации независимых учебных копий.

## What Changes

- Уточнить исходную спецификацию credit-calculator по существующему поведению сервиса, без реализации нового ограничения суммы.
- Сделать check и setup проверками самого Store, независимыми от сервисного checkout.
- **BREAKING**: удалить из Store команды установки зависимостей, запуска и HTTP-проверки сервиса; выполнять проверки реализации в сервисе.
- Оставить необязательное получение исходников сервиса для анализа, без автоматической регистрации Store и без проверки равенства спецификаций.
- Объяснить переход: самостоятельная ступень 3 использует repo-local OpenSpec; только отдельная рабочая ветка упражнения 3★ переходит к Store-only.
- Убрать дублирующие нормативные правила из CONTEXT.md, повтор пути из product.yaml и повторные проверки.
- Сохранить архив, официальные OpenSpec skills и оригинальный MTP grill-with-docs с provenance.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `credit-calculator`: уточнить требования к существующему расчёту, ошибочному вводу и локальной обработке данных. Новый диапазон суммы относится к отдельному учебному Change limit-credit-amount.

## Impact

Изменяются спецификация Store, контекст, документация, project setup skill, npm-команды и собственные тесты метарепозитория. Сервисные runtime-тесты остаются в сервисе. Ступени 1, 2 и 3 являются самостоятельными учебными примерами, а не производными копиями Store.

Публикация, изменение реестра пользователя и миграция общей main сервиса в Store-only не входят в этот Change.
