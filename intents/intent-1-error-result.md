# Совместимость старого адреса

R1–R3 используют один рабочий замысел и его историю Git: [предоставленный пример разбора](../examples/clear-calculation-result.md) показывает возможное оформление, а в своей ветке ученик ведёт один актуальный файл `intents/clear-calculation-result.md`.
Этот адрес сохранён для старых ссылок; отдельный снимок замысла на каждую ступень не нужен.
